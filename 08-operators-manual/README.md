## Relevance to OS ROM work

This is the **user-facing** OS 3.0 reference (menus, disk, MIDI, SCSI, sync). It does **not** replace schematics or CPU datasheets, but it is useful for:

- Naming OS features / soft-key behaviour when reverse-engineering ROM UI code
- Disk / PAR / SET / SND / PGM file roles (Ch. 9)
- MIDI implementation expectations (Ch. 11 + charts)
- SCSI hard-disk usage notes
- Baseline for comparing later OS versions (3.11 / 3.12 / Vailixi 3.50 / floppy 3.16)
